# Orientation forms

Print one set for each session. These forms record personal information about staff (names and
signatures), so keep the filled-in sheets with the LGU's records, and do not post them in a chat or
a shared folder open to others. See
[How completion is recorded](README.md#how-completion-is-recorded).
