Correct the name

This account’s name was checked against the resident’s ID, so the resident cannot change it in the app. Correct it here only with a government ID in front of you that shows the new name — after a marriage or a court order, for example.

What the server does if you correct it:

  • The account’s name becomes the one you type. The resident’s digital ID shows it, and so do the office’s event lists.
  • The earlier name is kept in the account’s name history, with who corrected it and when.
  • The ID is not reviewed again: the account stays verified and keeps its digital ID.
  • The audit trail records that the name was corrected, not the names. The server keeps no reason.
  • The resident is not told in the app. Tell them at the counter.
