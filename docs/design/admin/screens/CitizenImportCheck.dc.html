When you import
  • New citizens are added to the registry for San Juan, with “Barangay RBI, Nov 2026” noted as the source.
  • Updated records keep everything the file leaves empty.
  • Merged rows join the existing record; the registry keeps one record per person.
  • Skipped rows are listed in a report you can download afterwards.
